# Results

The authoritative results for the current public reproduction are:

- `price_mask_conformal_multiseed_results.json`
- `price_negative_control_results.json`
- `internal_circuit_conditioning_results.json` — direct fixed-network internal-subgraph conditioning, exhaustive same-input counterfactuals, matched control, oracle agreement, and forward-hook execution audit.
- `multicircuit_contract_transfer_results.json` — three internal circuits, five seeds, held-out continuous contract generalization, matched price-blind and discrete-anchor baselines, forward-hook execution audit, and simulated separable runtime-calibration transfer.
- `multicircuit_runtime_state_calibration_results.json` — one ordinary-Linux same-core contention run. Timing is intentionally environment-sensitive; the accompanying note reports that route-specific P99 separation was not stable across independent invocations.
- `joint_self_specialization_results.json` — five-seed joint-from-scratch specialization, capability-forgetting ablation, matched price-blind control, relative-price scale-invariance ablation, and gradient-separation diagnostic.
- `topology_search_discovery_results.json` — constrained 27-topology supernet search without complete-route labels, five-seed price-aware/price-blind comparison, global-oracle and local-pruning diagnostics, plus a 4-bit-parity stress result.

These files are regenerated by the scripts in `experiments/`.

Earlier exploratory copy-vs-compute JSON files were removed during the audit because they used an older architecture, older parameter counts, and the ambiguous label `memory cost`. Their substantive exploratory conclusions are retained in `notes/experiment_report.md` and `notes/readiness_report.md` where relevant.
